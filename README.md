# CPU — 4-Wertigkeiten-Modul

## Zweck
Die CPU erzeugt vier Kern-Wertigkeiten:
- Last
- Takt
- Energie
- Zustand

Diese Werte werden an NC.vector weitergereicht.

## Funktionen
- Hardware-Last messen
- Energieverbrauch bestimmen
- Taktzyklen erfassen
- Zustand melden
